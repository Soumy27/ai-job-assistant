# Deploying CareerAI

Three pieces deploy independently: **backend → Render**, **frontend → Vercel**, **extension → load locally / Chrome Web Store**.

> Prerequisite: your code is pushed to GitHub (`.env` is git-ignored — never commit it).

---

## 1. Backend → Render (free tier)

1. Go to **render.com** → **New +** → **Blueprint** → connect this GitHub repo.
2. Render reads [`render.yaml`](render.yaml) and creates the `careerai-backend` web service.
3. Fill the prompted env vars:
   - `DATABASE_URL` — your Neon connection string
   - `GEMINI_API_KEY` — optional (app falls back to templates/regex without it)
   - `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
   - `GOOGLE_REDIRECT_URI` — `https://<your-render-url>/api/gmail/callback`
   - `FRONTEND_URL` — your Vercel URL (set after step 2; you can update later)
   - `JWT_SECRET` — auto-generated by Render
4. Deploy. Note your backend URL, e.g. `https://careerai-backend.onrender.com`.
5. Verify: open the URL → should show *"AI Job Assistant API Backend is running"*.

> Free Render instances sleep after inactivity; the first request after idle takes ~30s to wake.

---

## 2. Frontend → Vercel

1. Go to **vercel.com** → **Add New** → **Project** → import this repo.
2. **Root Directory:** `frontend`. Framework preset: **Vite** (auto-detected).
3. **Environment Variables:** add `VITE_API_BASE` = your Render backend URL (from step 1.4).
4. Deploy. Note your frontend URL, e.g. `https://careerai.vercel.app`.
5. Go back to Render and set `FRONTEND_URL` to this Vercel URL, then redeploy the backend (so the Gmail OAuth callback redirects to the right place).

---

## 3. Update Google OAuth for production

In **Google Cloud Console → Clients → your OAuth client**:
- Add an **Authorized redirect URI**: `https://<your-render-url>/api/gmail/callback`
  (keep the localhost one too for local dev).
- The localhost redirect stays; production uses the new one via `GOOGLE_REDIRECT_URI`.

For public (non-test) Gmail users you'd also submit the app for **Google verification**; in testing mode only added test users can connect.

---

## 4. Extension → point at production

In [`extension/config.js`](extension/config.js), set:
```js
var API_BASE = 'https://careerai-backend.onrender.com';
var WEB_BASE = 'https://careerai.vercel.app';
```
Reload at `chrome://extensions`. (To publish, zip the `extension/` folder and submit to the Chrome Web Store — a one-time $5 developer fee.)

---

## Summary of env vars
| Where | Vars |
|-------|------|
| Render (backend) | `JWT_SECRET`, `DATABASE_URL`, `GEMINI_API_KEY`, `GOOGLE_CLIENT_ID/SECRET`, `GOOGLE_REDIRECT_URI`, `FRONTEND_URL` |
| Vercel (frontend) | `VITE_API_BASE` |
| Extension | `config.js` `API_BASE`, `WEB_BASE` |
